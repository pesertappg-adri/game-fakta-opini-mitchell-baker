GAME MITCHELL BAKER — INTERAKTIF

Cara menjalankan:
1. Buka Game_Mitchell_Baker_Interaktif.html menggunakan Chrome, Edge, atau browser modern.
2. Tidak memerlukan instalasi atau koneksi internet.
3. Game memuat empat pernyataan Fakta/Opini secara berurutan.
4. Setelah menjawab, baca umpan balik Mitchell dan tekan LANJUT SOAL.

Catatan perubahan:
- Pernyataan usia diubah dari 29 menjadi 19 tahun.
- Pertanyaan, kunci jawaban, dan pembahasan lain dipertahankan dari game sumber.
- Ilustrasi pemain dari game sumber digunakan kembali dan telah tertanam di dalam HTML.
- CSS dan JavaScript telah disusun ulang untuk alur satu soal per layar, popup umpan balik, skor, progres, dan hasil akhir.
